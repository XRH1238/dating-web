# 照片与视频拖拽上传设计

日期：2026-08-28

## 目标

为网站内全部媒体上传入口增加拖拽能力，同时保留文件选择器。相册、出游记录和时间胶囊均支持照片与视频，每次最多接收 20 个文件，并在上传或提交前提供对应预览。

## 范围

本次包含三个入口：

1. “我们的相册”的即时上传入口；
2. “出游记录”表单中的媒体附件入口；
3. “时间胶囊”表单中的媒体附件入口。

本次不增加独立媒体管理页、不增加视频转码、不生成服务端缩略图，也不修改 Supabase 表结构或存储策略。

## 交互设计

采用已确认的 A“完整拖拽区”方案。

- 相册使用宽版拖拽区，显示“拖入照片或视频”和“每次最多 20 个文件”。整个区域可点击并触发原生文件选择器。
- 出游记录和时间胶囊使用相同视觉语言的紧凑版拖拽区，避免表单过长。
- 拖拽进入有效区域时，边框、背景和提示文字进入高亮状态；离开或放下文件后恢复。
- 三个原生文件输入均使用 `accept="image/*,video/*"` 和 `multiple`，保证桌面点击选择与移动端选择继续可用。
- 没有待处理文件时不显示空白缩略图；选中文件后才生成预览网格。
- 照片以裁切缩略图显示；视频使用带原生播放控件的 `<video>` 预览。
- 所有状态和错误提示通过现有或新增的 `aria-live` 状态区域对辅助技术可见。

## 文件接收规则

统一的媒体文件处理逻辑同时服务点击选择和拖拽：

- 只接受 MIME 类型以 `image/` 或 `video/` 开头的文件；不符合条件的文件不会进入上传队列。
- 单次选择或拖入最多接收 20 个有效文件。
- 出游记录和时间胶囊允许通过多次选择或拖入继续追加，草稿队列总数最多 20 个；重复达到上限后保留已有文件并提示。
- 相册每次拖入或选择后立即上传该批次中最多 20 个有效文件。
- 当一个批次同时包含有效和无效文件时，保留有效文件，并明确提示被忽略文件的数量。
- 当超过数量限制时，只接收允许范围内的前若干个有效文件，并提示上限为 20 个。

## 数据与渲染

上传仍沿用现有 `love-photos` Storage bucket 和现有上传函数，不执行数据库迁移。

- 出游记录与时间胶囊的 JSON 媒体对象可保存文件名、URL、路径和 MIME 类型；旧数据没有 MIME 类型时继续兼容。
- 相册的 `love_photos` 表保持现有字段。媒体类型通过对象中的可用 MIME、Data URL 前缀、文件扩展名或 URL 扩展名依次判断。
- 新增一个统一媒体渲染辅助逻辑：照片生成 `<img>`，视频生成带 `controls`、`preload="metadata"` 的 `<video>`。
- 旧照片记录仍按照片渲染，不改变已有内容。
- 视频不自动播放，避免流量、声音和移动端策略问题。

## 错误处理

- 非照片或视频：忽略并显示中文提示。
- 超过 20 个：截取允许数量并提示上限。
- 文件读取失败：保留其他可预览文件，并在对应表单状态区显示失败信息。
- 云端上传失败：沿用现有离线回退和云端状态提示；表单上传失败时继续保留草稿，避免用户重新选择。
- 大视频在离线回退时可能占用较多内存；本次不额外实现压缩或持久化视频缓存。

## 样式与响应式

- 复用现有玫瑰色、奶油色、虚线边框和圆角设计语言。
- `is-dragover` 状态只增加视觉反馈，不改变布局尺寸，避免拖拽时页面跳动。
- 预览网格在桌面端显示较多列，在移动端缩减列数；照片与视频使用一致比例和圆角。
- 键盘焦点样式与拖拽高亮均保持清晰对比度。

## 测试策略

按 TDD 的红—绿—重构流程实施：

1. 先新增失败测试，验证三个输入均接受照片和视频、允许多选，并包含统一拖拽区标记；
2. 验证点击选择和拖拽使用同一文件筛选逻辑；
3. 验证只接收照片与视频、最多 20 个、表单多批次追加不超过 20 个；
4. 验证拖拽事件阻止浏览器默认打开文件，并正确切换高亮状态；
5. 验证照片生成 `<img>`、视频生成 `<video controls>`，旧照片数据仍兼容；
6. 运行完整 Node 测试套件，并在 Codex 内置浏览器中分别检查桌面和移动布局、拖拽反馈、照片预览与视频播放。

## 预计修改

- `index.html`：更新三个媒体输入的接受类型、文案、拖拽区结构和状态区域。
- `script.js`：增加统一筛选、数量限制、拖拽绑定、媒体预览与媒体渲染逻辑。
- `styles.css`：增加拖拽区、高亮状态及照片/视频预览样式。
- `tests/`：增加上传交互与媒体渲染测试，并更新原有“最多 6 张”的断言。

仓库当前在上述正式文件中已有未提交的首页改动。实施时只做与媒体上传直接相关的局部编辑，不覆盖、回滚或提交这些既有改动。

## 验收标准

- 三个入口都可以点击选择或拖入照片与视频；
- 每批最多接收 20 个有效文件，表单草稿总数不超过 20 个；
- 非媒体文件和超限文件会被安全忽略并给出明确提示；
- 照片和视频在上传前及保存后使用正确元素显示；
- 旧照片数据继续正常显示；
- 所有自动化测试和构建级检查通过；
- 桌面与移动布局无明显溢出，键盘用户仍能操作文件选择入口。
