# 市级行政区标签防重叠设计

## 背景与目标

当前地图在缩放比例达到 3 倍时一次性显示全部市级行政区名称。密集地区的标签没有碰撞检测，因此会互相覆盖。

目标是在保留市级行政区信息的前提下，让标签随缩放等级逐步显示，并保证当前旅行路线、已访问城市等重点标签优先可见。

## 交互设计

- 缩放低于 3 倍：只显示省级标签。
- 缩放达到 3 倍：进入市级详情，优先显示重点城市与空间充足的普通城市。
- 继续放大：逐步缩小标签之间要求的最小间距，从而显示更多城市。
- 缩放或拖动地图后：重新计算当前视口中的标签位置和可见性。
- 重点城市：旅行计划路线起终点、已访问城市和带照片城市。重点标签始终优先于普通标签。
- 省级标签与市级标签保持互斥，避免两个层级同时形成视觉噪声。

## 技术设计

### 标签数据

生成市级 SVG 标签时，为每个 `<text>` 增加城市名称与优先级相关的数据属性。地图状态更新时读取这些标签，而不重复构建完整地图几何。

### 碰撞检测

采用屏幕空间矩形碰撞检测：

1. 将标签的地图坐标转换为当前视口坐标。
2. 重点标签先参与布局，普通标签随后参与。
3. 根据文字长度、字号和当前缩放估算屏幕矩形。
4. 若候选矩形与已保留矩形相交，则隐藏该标签。
5. 缩放越大，最小间距越小，从而逐步展示更多标签。

该策略只处理标签可见性，不改变行政区边界、路线和照片标记。

### 更新时机

复用现有 `requestAnimationFrame` 地图更新机制，在 `applyMapView` 更新变换后同步执行标签布局，避免拖动时重复触发布局抖动。

## 边界与降级

- 标签位于视口外时直接隐藏，不参与碰撞计算。
- 重点标签彼此过近时仍按稳定顺序保留，避免每次拖动产生随机闪烁。
- 如果无法获取标签坐标，保持该标签隐藏，不影响地图其他功能。
- 移动端使用更大的最小间距，避免小屏幕重新出现拥挤。

## 测试与验收

- 回归测试先证明当前实现会让密集城市标签矩形相交。
- 单元测试覆盖：重点标签优先、重叠标签隐藏、非重叠标签保留、放大后显示数量增加、视口外标签隐藏。
- 浏览器验收：在 3 倍、6 倍和 10 倍缩放下检查市级标签无明显重叠，并确认缩放和拖动流畅。
- 确认省级标签、市级标签、旅行路线、已访问城市标记和地图控制按钮均保持正常。

## 范围

本次只调整本地 SVG 中国地图的市级标签布局，不改动 Supabase 数据、旅行计划表单、照片上传或备用高德地图代码。
