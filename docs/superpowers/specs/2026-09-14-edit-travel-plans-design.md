# 出游计划编辑设计

## 目标

让登录用户可以修改已经保存的出游计划，而不是只能删除后重新创建。

## 交互

- 每张计划卡在删除按钮旁增加“编辑”按钮。
- 点击后复用现有计划表单，并填入标题、日期、描述、去程和返程路线。
- 编辑时面板标题显示“编辑出游计划”；关闭或取消后恢复添加状态。
- 保存成功后更新原计划并重新渲染页面；保存失败时保留当前输入，方便重试。

## 数据与兼容性

- 使用现有计划记录 ID 调用主 Supabase 的 `update`，不新增表或字段。
- 本地兜底数据更新同一条计划，不生成重复计划。
- 现有计划和旧数据格式保持兼容，其他模块与 Storage 不变。

## 验证

- 自动化测试覆盖编辑按钮、表单回填、按 ID 更新、失败保留输入以及关闭后重置编辑状态。
- 运行完整测试，并在本地浏览器检查添加、编辑和取消流程。
