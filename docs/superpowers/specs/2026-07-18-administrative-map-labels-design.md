# 中国地图行政区名称与省名避让设计

## 目标

中国旅行地图只标注正式行政区名称，不显示自然保护区、林场等非行政区名称。初始省级视图完整显示全部省级行政区名称且互不重叠；放大进入市级视图后，只显示真正的地级行政区名称，并在可视空间允许时逐步显示全部市名。

## 范围

本次调整只涉及 SVG 中国地图的行政区标签、名称规范化和标签布局。地图配色、边界线、路线、照片标记、拖拽与缩放交互保持不变。

## 行政区数据规则

### 省级行政区

- 使用 `china-provinces-data.js` 中的省级边界。
- 显示 34 个省级行政区的完整正式名称，包括省、自治区、直辖市和特别行政区后缀。
- 不使用简称替代正式名称。

### 市级行政区

- 市级标签以地级行政区为范围，包括地级市、自治州、地区和盟。
- 使用行政区划编码区分地级行政区与数据中混入的县级单位或其他特殊区域；不能只依靠名称结尾猜测行政级别。
- 名称根据行政级别补全正式后缀。例如，地级编码对应的“甘南藏族自治”显示为“甘南藏族自治州”。
- 数据中的“太子山天然林保护”“莲花山风景林自然保护”等保护区名称不生成标签。
- 非行政区几何仍可保留为地图底色，避免地图出现空洞，但不能作为可选择、可记录或可显示的城市名称。
- 所有有效地级行政区都必须进入标签候选集合；碰撞布局只能控制当前缩放级别下的可见性，不能从数据层永久遗漏行政区。

## 省级标签设计（方案 A）

### 视觉样式

- 沿用上一版省名的深玫红色、粗体、白色描边和居中定位风格。
- 常规省名保持单行。
- 较长的自治区和特别行政区名称允许在语义边界处分成两行，保持整体居中。

### 防重叠布局

- 初始省级视图要求 34 个名称全部同时显示，不允许通过隐藏标签解决碰撞。
- 默认位置使用省级几何中心。
- 对北京、天津、上海、香港、澳门及其他密集区域配置稳定的小幅位置偏移。
- 布局完成后运行碰撞检测；若仍有冲突，按固定顺序在有限范围内进行二次水平或垂直避让。
- 窄屏优先增加换行并适度缩小字号，但保持可读下限；不得隐藏任何省级名称。
- 不使用引导线，保持与上一版接近的简洁观感。

## 缩放与标签切换

- 地图复位和省级缩放阶段显示省名，不显示市名。
- 达到市级详情阈值后隐藏全部省名，显示市级候选标签，避免两级名称同时出现。
- 市级标签继续使用碰撞检测：当前缩放不足时只显示不重叠的市名；继续放大或平移到相应区域后，所有视口内的有效地级行政区名称应能出现。
- 地图缩放必须围绕正确的 SVG 中心执行，不得再次引入 CSS 与 SVG 双重缩放中心。

## 组件边界

- `map-label-layout.js`：负责行政区名称规范化、行政级别判断、省级标签避让、市级标签碰撞和地图平移限制。
- `script.js`：负责读取 GeoJSON、生成带稳定标识和行政级别元数据的 SVG 标签，并在缩放、拖拽、复位和窗口变化时调用布局模块。
- `styles.css`：负责省级与市级标签的颜色、字号、描边、换行和缩放视觉规则，不承担位置计算。

## 异常与回退

- 缺失或无法识别行政区划编码的记录不应被误标为地级行政区；开发环境记录诊断信息，页面继续显示其他有效标签。
- 如果窄屏避让空间不足，继续缩小到可读下限并使用两行名称；省级标签仍不得隐藏。
- 数据缺失时沿用现有地图数据加载失败提示。

## 验证标准

- 自动化测试覆盖 34 个省级名称全部进入布局结果、长名称换行、密集区域无碰撞和窄屏无隐藏。
- 自动化测试覆盖保护区名称被排除、地级自治州后缀补全、县级单位不被误判为地级单位，以及所有有效地级行政区均进入候选集合。
- 集成测试确保省级和市级标签不会同时显示，CSS 不包含会与 SVG 变换叠加的缩放中心。
- 在内置浏览器中验证桌面宽屏、当前窄屏、地图复位、连续放大、平移及窗口尺寸变化。
- 省级模式下 34 个名称全部可见且边界框互不重叠；市级模式下视口内可见标签互不重叠，继续放大后标签数量按空间增加。
