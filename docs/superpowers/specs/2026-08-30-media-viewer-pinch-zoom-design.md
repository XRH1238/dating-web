# 高清照片查看器双指缩放设计

## 目标

让高清照片查看器在手机和平板上支持双指捏合缩放，并在 Mac 上支持触控板缩放，同时保留按钮、键盘、鼠标与单指拖动能力。

## 范围

- 手机和平板：两根触控指针的间距变化控制缩放，两指中点作为缩放中心。
- Mac：Chrome 等浏览器通过 `Ctrl + wheel` 形式的触控板捏合事件缩放；Safari 额外监听 `gesturestart`、`gesturechange`、`gestureend` 作为兼容路径。
- 普通鼠标滚轮位于查看器内时也可缩放照片。
- 一根手指或鼠标在照片放大后继续拖动照片。
- 现有缩放按钮、键盘快捷键、复位、切换照片和实况照片播放保持可用。

不修改照片文件、上传流程、云端数据、相册分类或记录内容。

## 交互规则

1. 缩放范围继续限制为 25%–500%。
2. 缩放围绕手势焦点执行：双指使用两指中点，触控板和滚轮使用光标位置，Safari 手势使用当前手势中心或查看器中心。
3. 双指开始后立即取消单指拖动和实况照片长按计时，避免误播放。
4. 双指结束且仍剩一个触点时，以剩余触点重新建立拖动起点，避免照片突然跳动。
5. 手势进行时暂停 CSS 缩放过渡，使照片紧跟手指；结束后恢复原有过渡。
6. 事件只在高清查看器舞台内拦截，避免缩放整个页面；查看器关闭后不保留手势状态。

## 架构

在 `media-viewer.js` 中增加可独立测试的纯函数：

- `pointerDistance(a, b)`：计算两个触点距离。
- `pointerMidpoint(a, b)`：计算两个触点中点。
- `zoomAroundPoint(state, nextScale, focalPoint, bounds)`：保持焦点下的图片内容稳定，并复用既有 `clampScale`、`clampPan` 做边界约束。

浏览器层维护活动指针集合和当前捏合会话：

- `pointerdown` 加入触点；达到两个触点时创建捏合基准。
- `pointermove` 根据距离比例计算目标缩放，并调用 `zoomAroundPoint`。
- `pointerup` / `pointercancel` 移除触点并安全结束或降级为拖动。
- `wheel` 使用连续倍率缩放，焦点为事件坐标。
- Safari `gesturechange` 使用手势开始时的缩放乘以 `event.scale`。

## 错误与兼容处理

- 距离为零、无效坐标或无效缩放值时保持当前状态，不产生 `NaN`。
- Pointer Events 为主路径；Safari 手势事件只作为 Mac 触控板补充，不与正在进行的双触点手势重复执行。
- 视频和 Apple 实况播放器继续使用现有播放逻辑；双指手势不会启动长按播放。

## 测试与验收

先通过 TDD 增加失败测试，再实现：

- 两点距离和中点计算正确。
- 围绕中心缩放时位置不漂移。
- 围绕非中心焦点缩放时，焦点下内容保持稳定。
- 缩放和平移继续受到 25%–500% 与可见边界限制。
- 集成测试确认双指 Pointer Events、Mac `wheel`、Safari gesture 监听以及手势态样式存在。
- 运行完整 Node 测试和 JavaScript 语法检查。
- 在可用的浏览器中检查查看器打开、按钮缩放、拖动以及事件绑定；真实双指与 Mac 触控板手感由用户在设备上最终确认。
