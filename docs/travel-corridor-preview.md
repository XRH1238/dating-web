# 旅行照片长廊 · 本地开发记录

开发分支：`codex/travel-photo-corridor`，基于线上 `origin/master` 的 `73c2b8d`，原工作区未改动。

## 本地运行

在本工作区执行 `python3 -m http.server 4187 --bind 127.0.0.1`，访问 <http://127.0.0.1:4187/>。
在浏览器自行登录已有账号；登录信息不应粘贴到聊天或写进仓库。
本实现没有内置旅行照片、照片地址清单或用户凭据。

## 实现

- `travel-corridor.js`：从现有 `state.photos` 读取照片。`travel-corridor-selection.js` 保存八张人工选片的行标识、顺序与简短说明，不包含图片文件或媒体地址；若这些照片均被移除，则按横竖比例和城市差异回退选择，最多 14 张。最多抽样 36 张、并发六张读取原始尺寸；维持照片原始比例和颜色。
- `travel-corridor.css`：深灰摄影空间、手机布局、平面浏览和回忆弹窗。
- GSAP 3.14.2 和 ScrollTrigger 在 `assets/vendor/` 本地加载；上游版权与许可链接保留在文件头。
- 回忆根据同一照片的 URL/path 或相册里已有的手动旅行关联匹配，不凭城市猜测。没有匹配记录时，显示照片所属相册信息。
- 保留五项功能、现有数据访问、Live Photo 与高清查看器。沿用线上成员权限、账号隔离缓存、退出清理和媒体签名读取；退出后额外清空长廊 DOM 与回忆弹窗。
- 系统减少动态效果时采用平面浏览；手动平面切换、方向按钮、原生滚动与键盘 Tab/Enter/Esc 均可使用。
