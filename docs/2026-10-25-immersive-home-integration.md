# 照片长廊与完整旅行簿整合

本次只在 `codex/travel-photo-corridor` 本地工作区实施，未提交、合并、推送或发布。

## 实现

- 将已确认的深蓝星尘风景长廊接入 `index.html`，资源为相对路径，可随原项目部署到子目录。
- `immersive-corridor.js` 使用原长廊的数据整理函数，仍由 `script.js` 传入登录/成员状态、相册、记录和私密媒体解析器。
- 照片回忆中的“查看完整记录”改为同一文档的记录锚点。
- 保留原旅行簿、表单、对话框与认证标记。原业务脚本、数据客户端、权限和存储配置未修改。
- 不带入比较板、隐藏后续内容的规则、原型测量脚本或机器绝对路径。照片原文件和签名链接均未写入仓库。
- 长廊高度因异步照片加载或模式切换改变时，保留下方旅行簿的阅读位置。
- 首页使用独立颜色变量，避免影响浅色表单。中等宽度记录区改为单列，操作按钮允许换行。

## 验证

- Node 测试 388 项通过；新增选片、相机几何、视锥裁剪、粒子生命周期与整合资源测试。
- 原旅行簿、表单和对话框 HTML 与修改前逐字一致。
- 浏览器中长廊 12 张照片加载成功，导航可进入出游记录，离开长廊后星尘暂停。
- 记录表单可以打开和关闭，文字保持深色；未提交任何业务数据。
- 手机检查宽度 375px，无页面横向溢出；记录和相册可到达，相册 18 张。
- 主预览后续发生原登录会话失效，私密长廊清空并显示登录提示，无脚本异常。已请用户自行重新登录以继续个人验收。
- 保留上一版已知限制：快速反向滚动仍可能有偶发长帧；未宣称所有设备都稳定 60fps。
